Privacy Policy

This policy describes DESIGN-AI-DAILY's personal Blogger integration and editorial workflow. It is not a claim that public launch, Production authorization or hosted automation has been completed.

Google data accessed and purpose

With the operator's express authorization, the application uses the Blogger API to read blog identifiers and metadata, and post identifiers, titles, bodies, labels, status and URLs needed to reconcile existing records and prevent duplicate drafts. It may create only separately approved drafts in the designated blog. Blogger authorization covers the account's blogs; the narrower blog allowlist and draft-only controls are application safeguards. Gmail, Contacts and Drive access are not requested by this integration.

How data is used

Google user data is used only to provide and protect the authorized Blogger editorial functions, verify draft results, reconcile uncertain requests and support recovery. It is not sold, used for advertising profiles or sent to Gemini for model training or article generation. Gemini generation inputs are separately reviewed public source material, not Google account credentials or account-derived post records. Use of Google user data is subject to the Google API Services User Data Policy, including its Limited Use requirements.

Storage, security and service providers

Client credentials and refresh tokens are currently stored in a dedicated macOS Keychain item. Access tokens stay in process memory. Credentials are excluded from source code, article files, Git commits, logs and evidence reports. Private editorial records, draft text, identifiers, URLs and recovery state are retained locally and in the existing private GitHub state branch. They are available only to the operator and any explicitly authorized private-repository collaborators. Google processes API requests; GitHub hosts the approved private backup.

A read-only GitHub Actions state-restoration workflow has been deployed and verified. That workflow does not use Blogger or Gemini credentials. Provider credential loading code exists, but provider Secrets have not been registered or used in the deployed workflow. Any later transfer to repository Secrets requires separate approval; macOS Keychain data is not automatically transferred. This notice must be reviewed before such deployment. No security control can guarantee permanent protection or uninterrupted token validity.

Retention, revocation and deletion requests

Records are kept only for the editorial, duplicate-prevention and recovery purposes described here and are reviewed when those purposes end. There is no implemented automatic deletion schedule. The operator can revoke access through Google Account third-party connections. Revocation does not itself erase previously stored drafts or backup history. Contact the operator to request review and removal of retained application copies; recovery records and private Git history require deliberate handling, and deletion is not claimed to be instantaneous. Content hosted by Google remains subject to Google's controls and policies.

Visitors, cookies and messages

The application has not added analytics, advertising, mailing lists or reader account forms. This does not mean the hosting providers use no cookies or service logs. The selected hosting service for these static information pages is GitHub Pages. GitHub logs visitors’ IP addresses for security purposes; its Privacy Statement explains its processing. These information pages were published on 21 October 2026. These static information pages do not receive OAuth tokens or account-derived Blogger post data. The separate Blogger journal and Google authorization remain subject to the Google Privacy Policy and Blogger's platform behavior. If you email the operator, your address and message are used to respond to that inquiry. External source links lead to those providers' own policies.

Contact and changes

Privacy contact: dkplayground@gmail.com. Policy changes will be reviewed against actual configuration before publication. Materially different data uses require updated notice and any required consent.

운영상 필요한 보존 목적이 끝나면 검토하며, 자동 삭제나 즉시 백업 삭제를 약속하지 않습니다. Google 계정 연결을 철회할 수 있고, 저장 사본 삭제 요청은 위 연락처로 할 수 있습니다. 철회만으로 기존 Blogger 글이나 Git 백업이 자동 삭제되지는 않습니다.
